# Real-Time Facial Expression Recognition

A lightweight, browser-based computer vision application that detects faces and classifies emotions in real-time.

## 🚀 Features
- **Real-time Detection:** Uses webcam feed for instant feedback.
- **Emotion Classification:** Detects Neutral, Happy, Sad, Angry, etc.
- **Privacy Focused:** All processing happens client-side in the browser.

## 🛠️ Tech Stack
- **JavaScript**
- **TensorFlow.js**
- **Face-api.js**

## 📂 Installation
1. Clone the repo: `git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git`
2. Open `index.html` in your browser.
